## Contents

### `notebook/`: Learning Path 0 of the Agentic AI course

This folder holds the lab notebooks I completed for **Learning Path 0** of the *Agentic AI* course:

| Notebook | Module | Topic |
|---|---|---|
| `M2_UGL_1_chart_generation_1.ipynb` | M2 | Chart generation with reflection |
| `M2_UGL_2_sql_reflection_1.ipynb` | M2 | Text-to-SQL with reflection |
| `M3_UGL_1_functions_to_tools_1.ipynb` | M3 | Turning Python functions into tools |
| `M3_UGL_2_email_assistant_1.ipynb` | M3 | Tool-using email assistant |
| `M4_UGL_1_component_eval_1.ipynb` | M4 | Component-level evaluation |
| `M5_UGL_1_customer_service_1.ipynb` | M5 | Customer service agent (planning) |
| `M5_UGL_2_market_research_1.ipynb` | M5 | Market research agent (planning) |

`notebook/project/` contains the final project, the **Local Expense Agent**. It is a small command-line agent that answers questions about fake expenses stored in SQLite and runs fully locally. It combines the course patterns: tool use, reflection, planning, human-in-the-loop and evaluation. See `notebook/project/README.md` for details.
